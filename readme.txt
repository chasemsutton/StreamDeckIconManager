Download StreamDeckIconManager{version}Setup.exe from GitHub Releases and run it.
Example: StreamDeckIconManager1.1.0.1Setup.exe

The setup downloads and installs the application automatically.
No separate zip download is required for users.

If you have a version older than 1.1.0.1
Uninstall
Delete  %LocalAppData%\Programs\StreamDeckIconManager
and the Start Menu / Desktop shortcuts if present.
